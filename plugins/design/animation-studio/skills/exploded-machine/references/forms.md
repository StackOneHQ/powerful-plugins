# Forms

The form is what the whole subject is drawn as. Use the one the user names, even if it is not
here. When they name none, find the subject's shape in the first table and start from the form it
suggests. The part lists are starting points: design any part that shows a component better, as
long as it belongs to the form and matches its neighbours' rim, line weight, detail and materials.

## Choosing from the subject's shape

| The subject is mostly... | Start from |
|---|---|
| a flow through stages (a pipeline, a stream, an integration) | Pipe run, or Jet engine when each stage transforms what passes |
| a transform (input becomes something else) | Jet engine |
| layers stacked on each other (an app stack, network layers) | Layer stack, Server rack or Device teardown |
| stages that hand off and fall away | Rocket |
| modules plugged into a platform | Space station, or Plain tube |
| infrastructure (hosting, compute, storage) | Server rack |
| narrowing down (search, ranking, vision) | Camera lens |
| timing (scheduling, orchestration, retries) | Watch movement |
| filtering (security, moderation, cleaning) | Filter cartridge, or Pipe run |
| a product's anatomy | Device teardown |
| none of these, or a metaphor would distract | Plain tube |

## The forms

Each form comes apart along one axis. "Along" means the parts separate end to end, like a pipe;
"stacked" means they separate upward, like layers lifted off a board.

### Jet engine (along)

A pipeline that transforms what goes through it.

| Job | Part |
|---|---|
| lets in | intake fan with a spinner |
| transforms | compressor stages, knurled rotor rims |
| does it all at once | combustor cans in a ring |
| measures | sensor ring with probe ports |
| lets out | exhaust nozzle, tapering |

### Pipe run (along)

Data pipelines, streaming, ETL, integrations.

| Job | Part |
|---|---|
| lets in | inlet flange or bell mouth |
| filters | Y-strainer housing |
| paces | control valve with a handwheel or actuator |
| measures | flow meter with a transmitter head |
| fans out | manifold header with branch outlets |
| lets out | outlet flange or keyed coupling |

Flanges carry bolt circles, and nuts sit on the face toward the camera.

### Plain tube (along)

The neutral choice, when a metaphor would distract. Every component is a section of one tube,
told apart by bands, fittings, ports and bulkheads rather than by shape.

### Rocket (along)

Staged work where each stage hands off and falls away.

| Job | Part |
|---|---|
| protects | payload fairing |
| the core | payload with its adapter |
| measures | guidance ring |
| hands off | interstage |
| stores | propellant tanks with domed ends |
| does it all at once | engine cluster with bells |

### Space station (along)

Modular platforms, plugins, extensible systems.

| Job | Part |
|---|---|
| lets in | docking port |
| protects | airlock |
| each service | a pressurised module with portholes |
| connects | truss segment |
| powers | a power module carrying the solar array wings |

The arrays are the power module's own features, not parts of their own. Keep them and any
radiators compact, so they don't cross the leader lines.

### Server rack (stacked)

Infrastructure, hosting, multi-tenant platforms. Each component is a rack unit.

| Job | Part |
|---|---|
| lets in | patch panel |
| protects | firewall unit |
| paces | load balancer |
| does it all at once | blade servers |
| stores | storage shelf with drive bays |

### Layer stack (stacked)

Layered architectures. Each component is a plate, lifted off the one below, with spacers, vias and
connectors between plates and a cover on top.

### Device teardown (stacked)

Product anatomy: an app, an SDK, a hardware product.

| Job | Part |
|---|---|
| the surface | glass and display |
| transforms | logic board with its chips |
| stores | battery |
| measures | camera module |
| calls out | antenna flex |

### Camera lens (along)

Search, ranking, vision: anything that narrows or focuses.

| Job | Part |
|---|---|
| lets in | front element with its glass |
| filters | filter thread ring |
| narrows | focus group, knurled grip |
| paces | aperture with blades |
| lets out | mount with bayonet lugs |

### Watch movement (stacked)

Scheduling, orchestration, retries, anything timed. Parts are thin plates and wheels, stacked.

| Job | Part |
|---|---|
| input | crown and stem |
| stores | mainspring barrel |
| transforms | gear train |
| paces | escapement |
| measures | balance wheel |

### Filter cartridge (along)

Security, moderation, guardrails, data cleaning: each stage removes something.

| Job | Part |
|---|---|
| lets in | inlet cap |
| filters coarse | mesh prefilter |
| filters fine | carbon block |
| filters finest | pleated membrane |
| measures | sensor cap |

## Stacked forms and the layout

A stacked form rises straight up the screen instead of along the diagonal. Put its label columns to
its left and right rather than below and above it, each leader starting from the side of its
plate, and give the plates a gap wide enough that each one's top face reads.
